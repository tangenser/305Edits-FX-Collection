# 305Edits FX Collection — Tracking 0.3.0

Windows 11 x64. Перенос анимации маски Premiere на выбранный видеоклип, текст, MOGRT, изображение или вложенную секвенцию. MCP Bridge для работы не нужен.

## Установка

Запустите 305Edits-FX-Collection-Setup-0.3.0.exe. В лаунчере выберите Tracking → Установить/Обновить и нужные версии Premiere. Закройте Premiere на время установки панели. Откройте Окно → Расширения → 305Edits Tracking.

Приложения обнаруживаются через реестр, папки Adobe и ярлыки меню Пуск. Для нестандартной установки есть «Указать путь…». Установка разрешена на непроверенные версии; совместимость их API и формата масок не гарантирована. «Установлен» и «Управлять» отображаются, когда текущая версия установлена для всех обнаруженных версий Premiere.

Обновления: «Установить пакет обновления…», выбрать .305fx, затем «Обновить» на карточке. Лаунчер при запуске и по кнопке «Проверить обновления» скачивает актуальный пакет из публичных GitHub Releases: https://github.com/tangenser/305Edits-FX-Collection . Вход в GitHub не требуется. Установка выполняется кнопкой на карточке с выбором версий Premiere. SHA256 проверяет целостность, но не удостоверяет издателя.

## Применение

1. Выполните трекинг маски средствами Premiere. Сохраните проект. Для Object Mask нужна папка <имя проекта> Masks рядом с проектом.
2. В Effect Controls выделите всю маску и нажмите Ctrl+C. Копирование только Mask Path или клипа на таймлайне не подходит.
3. В той же секвенции выделите один целевой клип. Исходный клип должен оставаться на прежнем месте.
4. Нажмите «Считать маску», выберите маску, Position, Scale и/или Rotation.
5. Выберите совмещение по исходному времени или от плейхеда. Нажмите «Применить трекинг».

Позиция целевого клипа сохраняется на текущем кадре диапазона переноса. Для смещения можно менять Anchor Point. Для текста используется Vector Motion, если доступен; иначе Motion. Уже анимированные выбранные параметры не перезаписываются. Для повторного применения сначала удалите их прежнюю анимацию в Premiere.

При применении маска считывается заново. Между копированием маски и применением не копируйте другие данные. Сглаживание: выкл./3/5/7 исходных кадров маски. Ключи записываются с частотой кадров секвенции.

## Данные и ограничения

- Контурная маска: Position — центр вершин; Scale/Rotation — приближение преобразованием подобия. Деформация и перспектива сводятся к общему масштабу и углу.
- Object Mask: Position — центр ограничивающего прямоугольника; Scale — квадратный корень отношения площадей. Изменение позы/формы объекта влияет на масштаб. Rotation в проверенных данных отсутствует; при его выборе панель возвращает ошибку.
- Проверены образцы AEMask2: Object Mask из 26.5.2 (226 кадров) и контурная маска из 27.1.0 Beta (41 кадр). Полный процесс в Beta не проверен. Старые типы масок и будущие форматы могут потребовать адаптации.
- В Premiere 26.5.2 проверена запись Position/Scale на текст: по 113 ключей с чтением конечных значений обратно. Тестовая анимация удалена, исходные значения восстановлены.
- Speed/Reverse не поддерживаются. Эффекты геометрии, Scale to Frame Size, нестандартный пиксель и сложные преобразования исходника требуют отдельной проверки. Точность трекинга определяется маской Premiere.
- Исходный клип определяется по имени и диапазону на таймлайне. Несколько совпадений отменяют операцию. Перенос между разными проектами/секвенциями не реализован.

## Сборка

Windows, .NET Framework C# compiler, Python 3.12.10 embedded x64 в runtime/, Inno Setup. NumPy/OpenCV в 0.3.0 не используются и не включаются. Лицензия Python в runtime.

runtime/python.exe build.py; tools/inno/ISCC.exe launcher/setup.iss. Артефакты в outputs/ относительно workspace. Проверки: runtime/python.exe tests/test_mask_transfer.py. Личные образцы буфера обмена в исходный архив не включены.

Иконка создана image_gen: Windows desktop application icon for 305Edits FX Collection; centered dark rounded-square tile, geometric 305 monogram, electric blue and icy white, restrained neon glow, high contrast, no additional text or Adobe logos.
